# TROUBLESHOOTING

| Symptom | Meaning |
|---|---|
| `SANDBOX_UNAVAILABLE` / code 126 | Isolation tools missing — will not run on host |
| `AJ_ERR_PROVIDER_UNAVAILABLE` | Provider not configured or not shipped |
| `REMOTE_EXECUTION_UNAVAILABLE` | No remote runtime registered |
| `AJ_ERR_INSTRUCTION_INJECTION` | Repository text tried to override policy |
| `AJ_ERR_CAPABILITY_EXPIRED` | Token TTL elapsed |
