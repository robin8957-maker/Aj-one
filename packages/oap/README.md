# Open Agent Protocol (OAP)

Contracts for ALJWHARAH ONE external agents. Any language can be a worker.
AJ Commander + Policy + Verifier stay above every worker.

```
capability.manifest → grants → budget → heartbeat → tools → artifacts
External agents cannot certify a mission.
```

See `schema.json`, `python/aljwharah_oap.py`, and `typescript/index.ts`.
